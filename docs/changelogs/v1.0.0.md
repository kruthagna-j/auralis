## v1.0.0 — April 15, 2026

### 🚀 Major Update
- Player service migration from just_audio and audioplayers to unified media_kit
- Implemented equalizer for all platforms
- Added Curve mode in equalizer
- Added gapless playback setting
- Added voice search feature 
- Audio URL caching based on provider and quality
- Added audio cache feature
- Increased related songs up to 250 in Queue from search screen
- Added translations support for Arabic, Gujarati, Indonesian, Kannada, Korean, Portuguese, Turkish, and Vietnamese
- Bumped versions of various dependencies and removed some unused ones

### ✅ Improvements
- Implemented loudness gain in volume control and removed separate loudness setting
- Added color-based volume control feedback based on volume level
- Language-specific home section titles (Applies on restart after language change)
- Redesigned navigation rail on large screens
- Reduced app launch time
- Implemented Native splash for Android
- Added disable battery optimisation settings
- Resume playback in no internet / long buffer situations
- Improved line switching in lyrics ui
- Added cancellation support for playlist downloads
- Added Wifi-only toggle for song downloads in settings
- Added support for all selection/ deselection in downloads screen
- Added Blur effect to player background (Default animation type only)
- Redesigned more options sheet of player UI
- Added new equalizer presets: Vocal Boost, Dance, Hip-Hop, Acoustic, Treble Boost
- Ui improvements in various screens
- Adjusted Marquee animation to 2 times instead of infinite loop

### 🛠 Fixes
- Fixed low-quality thumbnail in media notification
- Fixed YouTube / YT Music button in songs options of library
- Fixed translations in settings dropdown, downloads, and playlist screens
- Fixed local folder management include/exclude settings
- Fixed equalizer crash on OnePlus devices when playback starts
- Fixed audio playback crash on some devices
- Fixed issue of Audio playback in video mode
- Reduced delay in playing songs
- Adjusted padding in various screens of the app
